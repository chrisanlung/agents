## Accessibility baseline
- Contrast ≥ 4.5:1 text, 3:1 UI
- Focus visible on all interactive elements
- Keyboard navigable, logical tab order
- `prefers-reduced-motion` respected
- Target size ≥ 24×24 px (44×44 on touch)
